# lamp.iverfinne.no

3D-modellvisar bygd med Next.js (App Router) + react-three-fiber. Visar éin
modell om gongen på kvit bakgrunn, med navigasjon mellom modellane.

## Modellar

Ligg i `public/models/`:

- `clamp_lamp_01.glb`
- `lamp_02.glb`
- `microbit_2.glb`

## Køyr lokalt

```bash
npm install
npm run dev
```

Opnar på http://localhost:3000

## Deploy

Vert deploya automatisk til [lampe.iverfinne.no](https://lampe.iverfinne.no)
via Vercel ved push til `main`.
